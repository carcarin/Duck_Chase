# 🦆 Duck Chase

A browser-based 2D endless runner game built with vanilla HTML, CSS, and JavaScript.

## 🎮 Gameplay
Play as a duck frantically running from a chef down a three-lane track. 
Dodge obstacles, collect seeds, and activate a speed boost to survive as long as possible!

## ✨ Features
- Animated cutscenes for start and game over sequences
- Progressive difficulty — speed increases over distance
- Seed collection system with a 10-seed boost mechanic
- Pause, retry, and home screen functionality
- High score tracking via localStorage
- Scrolling movie-style credits

## 🕹️ Controls
| Key | Action |
|-----|--------|
| `A` or `←` | Move left |
| `D` or `→` | Move right |

## 🛠️ Built With
- HTML5 / CSS3 / Vanilla JavaScript
- FlipaClip (animations)
- Figma (UI/UX design)
